# Memoria técnica

- **App:** Tcanvapro, gestor de tareas mediante el tablero Canva.
- **Stack vigente:** React con Vite para la aplicación web; SQLite como base de datos.
- **Local:** aún no hay código ni `package.json` en el repositorio. Al configurar el proyecto, documentar aquí los comandos reales; usar `npm install` y `npm run dev` para desarrollo y el script de pruebas definido en `package.json` para verificar.
- **Convenciones:** código simple y sin complejidad anticipada; implementar solo lo descrito en la spec; interfaz en español de Perú y montos en soles; pedir solo datos imprescindibles; mantener secretos fuera del código; criterios de éxito verificables en la app.

Las reglas de producto viven en .specify/memory/constitution.md y el estado del producto en specs/README.md
